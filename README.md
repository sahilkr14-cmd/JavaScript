# JavaScript: Basic to Advanced 🚀

Welcome to the **JavaScript Basic to Advanced** repository!  
This project is designed to take you from **zero to hero** in JavaScript — starting from core fundamentals and progressing to advanced topics with real-world examples and hands-on code.

---

## 📚 What You'll Learn

### ✅ Basics
- Introduction to JavaScript
- Variables (`var`, `let`, `const`)
- Data Types
- Operators (Arithmetic, Comparison, Logical)
- Control Statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do...while`)
- Functions (Named, Anonymous, Arrow)

### ⚙️ Intermediate
- Arrays and Array Methods
- Objects and Object Methods
- DOM Manipulation
- Events and Event Handling
- Scope and Hoisting
- Closures
- Template Literals
- Error Handling (`try`, `catch`, `finally`)

### 🧠 Advanced
- ES6+ Features (Destructuring, Spread, Rest, etc.)
- Callbacks, Promises & Async/Await
- Fetch API & AJAX
- Local Storage & Session Storage
- OOP in JavaScript (Classes, Inheritance)
- Functional Programming Concepts
- JavaScript Modules (`import`, `export`)
- Event Loop & Asynchronous JavaScript
